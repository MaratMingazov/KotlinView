# Диорамы: «город» для структур данных

Рабочий документ, чтобы продолжить в следующей сессии: что делаем, как устроено, что решили и что дальше.

## Идея

Рядом с точной визуализацией структуры (плитка на `index.html`) показываем её же **«уютным островом»**
в изометрии: задачи — машины, очередь — места на дороге, пул — автомойка с боксами-воркерами,
семафор — шлагбаум со светофором перед площадкой. Город = ИТ-система, которая обрабатывает задачи.
Цель — чтобы хотелось сидеть и смотреть, как задачи проходят по очереди и выполняются.

Главный принцип проекта сохраняется: **картинка честная**. Обе колонки `twin.html` — два взгляда на одни
и те же события `/ws/events`; точное время показывает левая плитка, правая — «режиссёрская» версия.

| Структура | В городе |
|---|---|
| задача (`RUNNABLE_TASK`) | машина цвета задачи |
| `LinkedBlockingQueue` пула | белые рамки-места на дороге перед мойкой (до 5) |
| `ThreadPoolExecutor` (fixed) | автомойка: бокс = поток-воркер, маркиза — цвет потока |
| `Semaphore` + задача | шлагбаум и светофор (`свободно / всего`), площадка, домик = задача; машина = поток-раннер |

## Страницы

| Страница | Что | Сервер |
|---|---|---|
| `static/prototype.html` | две статичные диорамы на демо-снимках | не нужен, открывается как `file://` |
| `static/twin.html` | слева плитки (`FixedThreadPool`, `Semaphore`), справа их живые диорамы | нужен (`./gradlew :server:bootRun`, `http://localhost:8080/twin.html`) |
| `static/index.html` | все плитки, как раньше | нужен |

На `twin.html` пределы ввода: `nThreads` 1–3, `permits` 1–3, `durationMs` 1000–30000 (`min` / `max` у поля
и зажим при старте в `tiles.js`). Очередь fixed-пула — 5 (пресет сервера). Больше не рисуем: `LIMITS` в описании структуры.

## Файлы и слои

Порядок подключения важен (обычные скрипты, не ES-модули: модули Chrome блокирует на `file://`, а проверяем так):

```
iso-scene.js         → Iso               движок: палитра, цвета, геометрия, сцена, примитивы, тени, таблички, актёры
iso-objects.js       → IsoObjects        реквизит: остров, дорога, мост, машина (и машина-актёр), мойка, домик, шлагбаум, растения
diorama-kit.js       → Kit               набор: контракты, сеть маршрутов, актёры, модели, панель, статичный показ
diorama-pool.js      → PoolDiorama       описание структуры: автомойка = fixed-пул
diorama-semaphore.js → SemaphoreDiorama  описание структуры: шлагбаум = задача под семафором
tiles.js             → Tiles             плитки (вынесены из index.html), стили — tiles.css
```

Слои зависят только вниз: движок ничего не знает о реквизите, реквизит — о структурах, набор — о конкретных структурах.
Структура знает всё, что ниже, и store своей плитки — больше никто.

### `iso-scene.js` — движок

- **Мир и проекция.** Клетки `(x, y, z)`, изометрия 30°: `P(x, y, z) = [(x − y)·0.866·S, (x + y)·0.5·S − z·S]`,
  `S = 30`. «К зрителю» — больше `x + y`. Солнце слева-сзади: грань `+y` светлее, `+x` темнее, тени — в сторону `+x`.
- **Слои:** земля (по порядку добавления) → тени (мягкие, общая прозрачность группы) → контактные тени →
  объекты по глубине (`<g class="objects">`, у узла запомнена `__depth`) → таблички (`<g class="labels">`) → шапка.
- **Примитивы:** `box`, `prism` (любое основание — скруглённые формы), `disc`, `panel`, `gableRoof`, `flat`, `line`.
- **Тени:** `shadow` (эллипс), `castShadow` (оболочка основания и его сдвига по солнцу), `contact`.
- **Таблички:** `label(x, y, z, lines, { color, bar, permanent })`; постоянные — короткие счётчики, остальные —
  при наведении (`hover(node, label)`, один делегированный обработчик на сцену). `relabel` / `retitle` — замена
  на отрисованной сцене. `render({ hover, onHover })` сохраняет табличку под курсором между перерисовками.
- **Актёры** (`actor(key, build)`, после `render()`): объект строится один раз в начале координат в свои слои,
  `moveTo(x, y, z)` двигает всё одним `transform` (проекция линейна), узел встаёт среди неподвижных по глубине
  (`baseDepth + x + y`). `show(visible)`, `remove()`. id табличек — от ключа актёра.

### `iso-objects.js` — объекты

- `island` (берег — «дышащий» эллипс, склон, пляж, мелководье, камни, лодки), `road` (бордюры, пунктир, мосты
  за берегом), `zebra`, `stopLine`, `slot`, `paved`, `sign` (возвращает табличку-счётчик).
- `car` / `carNode` (вдоль `x`), `carNodeY` (вдоль `y`: `−y` — задом, красные фонари; `+y` — фары).
- **`carActor(s, key, color, options)`** — три модели (`x`, `y-`, `y+`), видна одна; позиция — центр машины;
  `go(points, { speed = 6, minMs = 450 })` — по точкам с плавным разгоном/торможением, направление перегона
  определяется само; `update(now)` — кадр.
- `washHouse` — **два объекта**: «зад» (пол, задняя стена, перегородки) и «перёд» (простенки, перемычка, торец,
  крыша, маркизы); машина в боксе встаёт между ними. Возвращает `bayCenter(i)`, `parkAt(i)`, `paintBay(i, worker)`.
- `trafficLight` возвращает `set(free, counter, details)`; `barrierGate`, `house`, `bench`, `streetLamp`, `picket`.
- `decorate(s, seed, keepOut)` — детерминированный разброс растительности (mulberry32) вне запретных зон.

### `diorama-kit.js` — набор

Всё, что одинаково у любой структуры. Контракты — JSDoc в начале файла (`Kind`, `Shape`, `Layout`, `ActorSpec`).

- **`Kind`** — описание структуры: `shapeOf(tile)` (когда пересобирать сцену), `layout(s, shape)` (сцена и места),
  `snapshotOf(tile, shape)` (снимок из store плитки), `actorsOf(snapshot, shape)` (кто где).
- **Места и сеть:** `Layout.places` (имя → центр) и `links`; путь — кратчайший по сети. `Kit.lane(places, names)` —
  связи «по цепочке» для мест на одной дороге. Группа мест `place: 'spot*'` — набор выберет свободное и закрепит.
- **Актёры:** новый — с `entry`; пропал из снимка — на `exit` и исчезает; облик сменился (`model`, `color`, `look`) —
  пересоздаётся на месте. Табличка фиксируется при создании.
- **Режиссёр времени** (`cast`): у актёра — план, очередь мест. Новое место не отменяет маршрут, а встаёт в план;
  доехал — стоит `DWELL_MS`, если дальше ещё есть куда (видно, что задача там была, даже если пробыла 1 мс);
  выезд — в конец плана. Если остаток плана при обычной скорости дольше `MAX_LAG_MS`, перегоны и стоянки
  ускоряются; вырос план в пути — текущий перегон пересчитывается. Параметры — `Kit.TIME`
  (`SPEED = 6` клеток/с, `MIN_MS = 450`, `DWELL_MS = 250`, `MAX_LAG_MS = 1000`).
- **Модели:** `Kit.models` — имя → конструктор актёра (сейчас `car` = `IsoObjects.carActor`). Облик отдельно от смысла.
- **`Kit.panel(kind)`** — живая диорама рядом с плиткой: сцена пересобирается при смене `Shape.key`, первая
  расстановка мгновенная, кадры — только пока кто-то едет. **`Kit.show(kind, snapshot, shape)`** — статичный показ.
- **Мелкая анимация реквизита:** необязательный `Layout.frame(now, actors)` — набор зовёт его на каждом кадре
  и передаёт, где актёры и куда едут (`{ key, x, y, target }`); вернул `true` — кадры нужны дальше, даже если все стоят.
- **Помощники для описаний:** `Kit.field(tile, name, max)` — число из поля спящей плитки (для «пустой» сцены),
  `Kit.progress(run, durationMs)` — доля выполнения запуска задачи.

### `diorama-pool.js`, `diorama-semaphore.js` — описания структур

У каждой: раскладка сцены константами, `LIMITS`, демо-снимок (`demo`, `demoShape`), `kind`.

- **Мойка:** места `entry`, `incoming`, `slot0…4`, `gate0…`, `bay0…`, `out0…1`, `exit`; бокс — только через свои ворота.
  `update`: шапка, счётчики очереди и выполненных, маркизы и таблички боксов.
- **Шлагбаум:** места `entry`, `wait0…3`, `gate`, `spot0…` (группа `spot*`), `lotOut`, `exit`.
  `update`: шапка, светофор, табличка домика, «+N» над очередью. `frame`: стрела (`barrierGate().setOpen(0…1)`)
  поднимается, когда к шлагбауму подъезжает машина, едущая на площадку (поток прошёл `acquire`), и опускается,
  когда проехала. Светофор — состояние семафора, стрела — событие «пропустили одного».

## Как добавить структуру

1. **Реквизит**, если нужного нет: функция в `iso-objects.js`, рисующая объект примитивами сцены. Если реквизит
   меняется на живой сцене — пусть вернёт ручку (как `trafficLight().set`, `washHouse().paintBay`).
2. **Описание** `static/diorama-<структура>.js` по образцу `diorama-pool.js`:
   - раскладка константами и `LIMITS` — сколько помещается;
   - `layout(s, shape)` — построить сцену, объявить `places` и `links`, вернуть `update(snapshot)` для обновления на месте;
   - `actorsOf(snapshot)` — `[{ key, place, color, model?, look?, label? }]`;
   - `snapshotOf(tile, shape)` — снимок из store плитки (только здесь знание о store) и снимок «ещё не запущено»;
   - `shapeOf(tile)` — от чего зависит неподвижная сцена (число боксов, мест);
   - `demo` и `demoShape` — для `prototype.html`.
3. **Новая модель актёра** (погрузчик, лодка) — запись в `Kit.models` с тем же интерфейсом, что у `carActor`.
4. **Страницы:** `<script>` после `diorama-kit.js`; в `twin.html` — ряд `{ view, panel: Kit.panel(kind) }`
   с пределами ввода из `LIMITS`; в `prototype.html` — `Kit.show(kind, demo, demoShape)`.
5. **Проверка без сервера:** `prototype.html` — скриншотом; `twin.html` — синтетическими событиями
   (`tiles[i].store.apply(env)` и `render()`).

## Кандидаты на рефакторинг

Что замечено и ещё не сделано. Обновляется по ходу работы.

- **Каркас сцены у обеих структур одинаковый:** остров → дорога (или две) → реквизит → `decorate` → места на полосе
  с `entry` / `exit` за мостами. Пока два случая — терпимо; на третьей структуре вынести «остров с дорогой» в набор.
- **Таблички актёров неизменны** после создания: живые (поток, прогресс) потребуют `relabel` для актёров.
- **Оттенок потока посчитан дважды** — `KV.threadHue` и `hue` в `iso-scene.js` (сознательно: `prototype.html` без
  `components.js`). Если появится общий модуль цветов — свести в один.
- **`Kit.panel` зависит от `KV.el`** (`components.js`) ради одной строки — можно заменить на `document.createElement`.
- **Файлы движка и реквизита перевалили за ~500 строк** (`iso-scene.js` ≈ 550, `iso-objects.js` ≈ 550). Реквизит
  будет только расти (бензоколонка, погрузчик, лодки) — разбить по темам: земля и дороги / транспорт / постройки /
  растительность; в движке — отделить таблички и актёров от примитивов.

## Решения и договорённости

- Стиль — только **cozy** (стили `minimal` и `city` удалены). Палитра — `Iso.PALETTE`.
- Оригинальный стиль в духе жанра градостроителей, а не копия облика конкретной игры.
- Цвет потока — один хеш на всё приложение: FNV-1a + «золотой угол» (`KV.threadHue` в `components.js`,
  копия — `hue` в `iso-scene.js`). Старый `(h·31 + c) % 360` давал соседним воркерам почти одинаковый цвет.
- Таблички на сцене — минимум: постоянные только счётчики, подробности — при наведении.
- Тестов пока не пишем; поведение в UI пользователь проверяет сам. Для статичных страниц можно смотреть
  скриншоты через Chrome DevTools (`file://`). Логику живых диорам проверяли **синтетическими событиями**
  в формате `/ws/events`, отправленными прямо в store плиток (`tiles[i].store.apply(env)`).
- Перед правками — коротко описать шаг и дождаться одобрения.

## Известные ограничения

- Процент в табличке бокса обновляется только на событиях.
- Задачи сверх 5 мест очереди не рисуются, пока не освободится слот; ждущих у шлагбаума больше 4 — тоже.
- В живой мойке нет «just submitted» (в store пула нет момента «задачу отдали в `execute`»).
- Дорога идёт по мировой оси `x` — на экране диагональ; в углах кадра всегда треугольники воды.
- На узких гранях скруглённых машин градиент даёт тонкие вертикальные полоски на стекле.

## Следующие шаги

1. **Мелкая анимация:** вспышка лампы светофора при переключении; растущая полоска прогресса над боксом
   (кадром через `Layout.frame`, а не событием).
2. **Табличка машины** — с потоком и прогрессом, пока она в боксе / на площадке.
3. **Другие пулы:** `CachedThreadPool` (SynchronousQueue — «окно выдачи» без площадки ожидания, боксы по требованию
   и снос по `keepAlive`), `SingleThreadExecutor`, отказ (`reject`) — машина разворачивается у въезда.
4. **Другие структуры:** `ReentrantLock` — однополосный мост; `Condition` — карман у моста; `ForkJoinPool` —
   у каждого бокса своя очередь, «угон» машин у соседа.
5. Возможно: полоса дорожек потоков под диорамой с честным временем (вариант из прототипов) и режим «строительства»
   (композиция структур в один город).
